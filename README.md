# 🎨 UI Replica

This repository contains **UI Replica Projects** where I recreate the frontend of popular platforms using **HTML** and **CSS**.  
Currently included:

- 📺 **Netflix Clone** – A landing page replica of Netflix with responsive design.  
- 🎵 **Spotify Clone** – A music platform UI replica showcasing layouts and styling.

---

## 🚀 Tech Stack
- **HTML5** – Page structure  
- **CSS3** – Styling & animations  

---
## 🌟 Features
- Pixel-perfect UI recreation  
- Responsive design for different screen sizes  
- Clean and reusable CSS

## ⚡ How to Run
1. Clone this repo  
   ```bash
   git clone https://github.com/saptarshi-bisoi/ui-replica.git
   ```
2. Open the project folder (e.g., NETFLIX-CLONE)
3. Run index.html in your browser
