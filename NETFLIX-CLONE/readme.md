
# 🎬 Netflix Clone (Replica)

A simple **Netflix UI replica** built with **HTML & CSS** (no frameworks).  
This project recreates the look and feel of Netflix’s home page — including header navigation, trending shows, and responsive grid-based content sections.

## 🚀 Features
- 🎨 Netflix-style dark UI
- 📌 Fixed navigation bar with logo, menus, and icons
- 🖼️ Responsive movie/show grids
- 🔍 Hover zoom effect on posters
- 📱 Fully responsive (desktop, tablet, mobile)
- ⚡ Lightweight — no external frameworks (only pure HTML + CSS)

---

## 📂 Project Structure
├── index.html # Main HTML file
├── style.css # Styles (Netflix dark theme)
